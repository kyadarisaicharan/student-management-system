# Student Management System

A full-stack web application developed using Spring Boot to manage students, courses, and enrollments efficiently.

## 🚀 Features
- Student, Course, and Enrollment Management (CRUD operations)
- Role-based Authentication (Admin/User) using Spring Security
- Pagination and Sorting for handling large datasets
- Dashboard with key statistics (students, courses, enrollments)
- RESTful APIs following MVC architecture
- Global Exception Handling
- DTO pattern with ModelMapper for clean data transfer
- Responsive UI using Thymeleaf, HTML, CSS, and Bootstrap

## 🛠️ Tech Stack
- Backend: Spring Boot, Spring MVC, Spring Security
- ORM: Hibernate (JPA)
- Database: MySQL
- Frontend: Thymeleaf, HTML, CSS, Bootstrap

## 📂 Project Structure
- Controller Layer
- Service Layer
- Repository Layer
- Entity & DTO
- Configuration & Exception Handling

## ▶️ How to Run
1. Clone the repository
2. Configure MySQL database in `application.properties`
3. Run the Spring Boot application
4. Access the application at: http://localhost:8081
